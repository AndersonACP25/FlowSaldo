# Contribuir a FlowSaldo

Crear feature/* o fix/* desde main actualizado, acotar el objetivo y abrir PR. Consultar AGENTS.md, MEMORY.md y DESIGN.md. Un archivo tiene un responsable de escritura durante una tarea; acordar cambios de contratos entre áreas.

Preparación: Node 24, pnpm install --frozen-lockfile y pnpm db:generate. Para demo pnpm start o pnpm web. Revisar TESTING.md y elegir checks según alcance. No incorporar datos bancarios reales ni tokens. Las contribuciones con IA siguen ai/policies.md y deben declarar límites de validación.

El PR explica problema, comportamiento resultante, evidencia de pruebas y limitaciones. Una aprobación de un agente no sustituye revisión humana ni protección de ramas. La política de PR es documental; este cambio no configura reglas administrativas en GitHub.
