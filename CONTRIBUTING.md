# Contribuir a FlowSaldo

Crear feature/*, fix/* o docs/* desde main actualizado, acotar el objetivo y abrir PR. Consultar AGENTS.md, MEMORY.md y DESIGN.md. Un archivo tiene un responsable de escritura durante una tarea; acordar cambios de contratos entre áreas.

Sigue la [guía desde el clon](docs/setup.md) para preparar Node, pnpm, la demo y la API. Revisar TESTING.md y elegir checks según alcance. No incorporar datos bancarios reales ni tokens. Las contribuciones con IA siguen ai/policies.md y deben declarar límites de validación.

El PR explica problema, comportamiento resultante, evidencia de pruebas y limitaciones. Una aprobación de un agente no sustituye revisión humana ni protección de ramas. La política de PR es documental; este cambio no configura reglas administrativas en GitHub.
